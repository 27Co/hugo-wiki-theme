# Sidebar Variables

The following variables are available for use in the homepage sidebar:

- `photo`: filename of the profile picture in `static/`
- `name`: name of the person or organization
- `role`: role or title
- `affiliation`: affiliation
- `location`: geographic location
- `email`: email address
- `github`: username in `www.github.com/<username>`
- `scholar`: google scholar username
- `linkedin`: username in `www.linkedin.com/in/<username>`
